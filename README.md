# Mario Kart 8 Deluxe Kart Builder
An interactive Excel-based kart builder for Mario Kart 8 Deluxe that allows users to create and analyze custom kart combinations by selecting a driver, kart body, tires, and glider. The workbook dynamically calculates and displays the resulting vehicle statistics for each combination.
With more than 700,000 possible combinations, the project demonstrates how Excel can be used to build an interactive configuration tool rather than simply functioning as a static spreadsheet.
